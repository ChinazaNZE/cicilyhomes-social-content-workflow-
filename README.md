# CicilyHomes Social Content Workflow

## Project Overview

This repository contains the final visual assets for the CicilyHomes Estates multi-platform social media campaign.

**Objective:**  
Help landlords in Abuja protect their properties by promoting verified tenants and verified listings.

**Platforms:** Instagram, X (Twitter), and LinkedIn  
**Format:** 3-slide carousel

---

## Final Deliverables

### Slide 1 – Problem
**Headline:** Still dealing with unverified listings?  
**Supporting line:** Only verified properties make it onto CicilyHomes.

Focuses on the issue of unverified listings and introduces the solution.

### Slide 2 – Solution + Proof
Features real product notifications showing verified tenants requesting viewings and sending messages, combined with a clear interface mockup.

Highlights trust and the verification process in action.

### Slide 3 – Call to Action
**Headline:** Ready to protect your property?  
**Supporting line:** Verified Listings. Trusted Agreements. Sustainable Living.  
**Primary CTA:** cicilyhomes.com

Strong closing slide designed to drive traffic to the website.
